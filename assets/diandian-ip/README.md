# 点点 IP 形象

点点是一只薄荷绿的小向导，圆润的定位点轮廓、两颗点点眼、奶油色挎包与珊瑚色背带构成主要识别元素。

性格：温和、机灵、有耐心。形象主张：陪你找到，也陪你出发。

## 交付文件

- `diandian-avatar.png`：透明底主形象，可用于助手头像、欢迎区和演示材料。
- `diandian-character-board.png`：展示板，包含主形象、打招呼／整理中／完成啦三种状态及配色示意。板上的状态图是展示示意，尚未分别导出为透明素材。

建议：头像完整展示头顶小芽、挎包与底部尖角，使用等比缩放，避免圆形裁切或放大；展示板适合直接用于产品介绍。后续拓展应保持轮廓、脸部比例和挎包方向一致。

本次使用内置图像生成工具生成，提示词保存在 `generation-prompts.txt`。主形象已接入 Demo 的搜索入口、创建界面、消息列表、对话和分享入口；展示板不作为界面素材使用。
